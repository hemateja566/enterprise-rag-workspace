# Frontend Codegnan

Daily frontend practice assignments from Codegnan Full Stack Development course.

## Overview

Organized day-by-day frontend exercises covering HTML, CSS, JavaScript, and React fundamentals.

## Structure

```
frontend_codegnan/
├── assignment/             # Graded assignments
├── day1/ - day3/          # Early HTML/CSS basics
├── contact.html           # Contact page
├── home.html              # Home page
├── index.html             # Main index
├── menu.html              # Navigation
├── register.html          # Registration form
└── README.md
```

## Daily Progress

### Days 1-3: HTML & CSS Fundamentals
- `day1/` - HTML structure, semantic elements, basic tags
- `day2/` - CSS basics, selectors, box model, flexbox intro
- `day3/` - CSS Grid, responsive design, media queries

### Assignments
- `assignment/` - Graded coursework submissions

### Template Pages
- `index.html` - Main entry point
- `home.html` - Home page layout
- `menu.html` - Navigation component
- `contact.html` - Contact form
- `register.html` - Registration form

## Topics Covered

| Week | Topics |
|------|--------|
| 1 | HTML5 semantics, CSS basics, Flexbox |

## Getting Started

```bash
git clone https://github.com/hemateja566/frontend_codegnan.git
cd frontend_codegnan

# Open any day's folder
open day1/index.html
```

## File Naming Convention

- `day{N}/` - Daily practice folder
- `assignment/` - Graded assignments
- `{page}.html` - Reusable template pages
