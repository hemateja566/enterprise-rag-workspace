# Travel Explorer

A travel planning and exploration web application.

## Status

⚠️ **This repository is currently empty.** The project structure and code need to be added.

## Planned Features

- Destination search and discovery
- Travel itinerary builder
- Flight/hotel price comparison
- Interactive maps
- User reviews and ratings
- Trip sharing and collaboration
- Weather integration
- Budget tracking

## Tech Stack (Planned)

- **Frontend**: React + Vite or Next.js
- **Backend**: Node.js/Express or Python/FastAPI
- **Database**: PostgreSQL/MongoDB
- **APIs**: Google Maps, Amadeus, OpenWeather
- **Authentication**: JWT/OAuth
- **Deployment**: Vercel/Netlify + Railway/Render

## Getting Started

Once code is added:

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend
npm install  # or pip install -r requirements.txt
npm run dev
```
