# Pre-Owned Wheels Hub

A marketplace platform for buying and selling pre-owned vehicles.

## Overview

Full-stack web application for a used car marketplace with listings, search, user accounts, and transaction management.

## Features

- Vehicle listings with detailed specs
- Advanced search & filters (make, model, year, price, location)
- User authentication (buyers & sellers)
- Seller dashboard for managing listings
- Inquiry/contact system
- Favorites/wishlist
- Image galleries
- Responsive design

## Tech Stack (Planned/Partial)

| Layer | Technology |
|-------|------------|
| Frontend | React / Next.js |
| Backend | Node.js/Express or Python/FastAPI |

## Getting Started

```bash
git clone https://github.com/hemateja566/pre-owned-wheels-hub.git
cd pre-owned-wheels-hub

# Frontend
cd frontend
npm install
npm run dev

# Backend
cd ../backend
npm install  # or pip install -r requirements.txt
npm run dev
```
