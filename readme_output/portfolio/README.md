# Portfolio

Personal portfolio website showcasing projects, skills, and experience.

## Overview

This repository contains the source code for my personal portfolio website. Built to highlight my development journey, projects, and technical skills.

## Features

- Responsive design for all devices
- Project showcase section
- Skills and technologies display
- Contact information
- Clean, modern UI

## Project Structure

```
portfolio/
├── index.html      # Main portfolio page
├── style.css       # Styling
├── script.js       # Interactive elements
├── assets/         # Images, icons, documents
└── README.md       # This file
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/hemateja566/portfolio.git
   ```

2. Open `index.html` in your browser.

## Customization

- Update `index.html` with your personal information
- Modify `style.css` for custom styling
- Add your projects to the projects section
- Replace placeholder images in `assets/`

## Technologies

- HTML5
- CSS3
- JavaScript

## Deployment

Can be deployed to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service
