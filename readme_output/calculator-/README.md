# Calculator

A simple, responsive calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clear and delete functions
- Keyboard support
- Responsive design
- Clean, modern UI

## Demo

Open `cal.html` in your browser to use the calculator.

## Project Structure

```
calculator-/
├── cal.html      # Main HTML structure
├── cal.css       # Styling
├── cal.js        # Calculator logic
└── README.md     # This file
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/hemateja566/calculator-.git
   ```

2. Open `cal.html` in your preferred browser.

## Usage

- Click buttons or use keyboard to input numbers and operations
- Press `=` or `Enter` to calculate
- Press `C` to clear all
- Press `DEL` or `Backspace` to delete last character

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
